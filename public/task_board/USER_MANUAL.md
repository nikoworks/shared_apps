# TaskBoard 運用マニュアル

## 1. 毎日の基本運用

各メンバーは、自分用URLからTaskBoardを開きます。

自分用URLを開くと、最初から自分のタスクだけが表示されます。

全体の進行状況を見たいときは、左メニューの「プロジェクト」を開きます。

## 2. 個人URLのコピー

管理者は「設定」→「メンバー管理」を開きます。

各メンバーの行にある「個人URL」ボタンを押すと、その人専用のURLをコピーできます。

## 3. タスクの一括入力

「今日のタスク」→「一括入力」から、Chatworkやメールで送られてきた内容を貼り付けます。

基本フォーマット:

```text
#task
プロジェクト名, タスク, 時間, 内容, 備考
A社サイト制作, トップページデザイン, 1, 画像差し替え
+, 画像制作, 1, バナー用画像の制作
?, 原稿確認, 0.5, プロジェクト名が不明
```

ルール:

- 1行に1タスクを書きます。
- 先頭がプロジェクト名なら、そのプロジェクトのタスクになります。
- 先頭が `+` または `＋` なら、直前と同じプロジェクトになります。
- 先頭が `?` または `？` なら、プロジェクト未設定タスクになります。
- 時間は `1`、`0.5`、`2` のように書きます。
- 備考には、困っていること、確認してほしいこと、助けてほしいことを書けます。

## 4. プロジェクト未設定がある場合

一括入力で「確認する」を押したとき、プロジェクト未設定タスクがあると警告が出ます。

「Chatwork文をコピー」を押すと、本人に送る修正依頼文をコピーできます。

本人は自分用URLからTaskBoardを開き、該当タスクの「編集」からプロジェクトを選び直します。

## 5. 確認・お願いの入力

タスクと同じ投稿の中に、メンバーへの確認・お願いも入れられます。

フォーマット:

```text
#ask
種別, 宛先, 内容, 関連プロジェクト, 期限
確認, 田中さん, A社LPの画像方向を確認してください, A社サイト制作, 今日中
依頼, 佐藤さん, B社パンフの原稿確認をお願いします, B社パンフ, 5/29
質問, 鈴木さん, バナーサイズは1080x1080で合っていますか？, A社広告, 今日中
共有, 全員, クライアントから素材が届きました, A社サイト制作, -
```

種別:

- `確認`: 判断してほしいこと
- `依頼`: 作業や対応をお願いしたいこと
- `質問`: 答えがほしいこと
- `共有`: 知っておいてほしいこと

## 6. タスクと確認・お願いを同時に送る例

```text
#task
A社サイト制作, トップページデザイン, 1, 画像差し替え
+, 画像制作, 1, バナー用画像の制作

#ask
確認, 田中さん, A社LPの画像方向を確認してください, A社サイト制作, 今日中
質問, 鈴木さん, バナーサイズは1080x1080で合っていますか？, A社広告, 今日中
```

## 7. 個人ページでの見え方

個人ページには、次の順番で表示されます。

1. あなた宛の確認・お願い
2. 自分が出した確認・お願い
3. 今日のタスク

確認・お願いが終わったら「完了」を押します。

「返信文」を押すと、Chatworkなどに返すための返信フォーマットをコピーできます。

## 8. まずの運用ルール

- 毎日前日までに、各メンバーが `#task` を送ります。
- 質問やお願いがある場合は、同じ投稿に `#ask` を足します。
- 管理者は一括入力で貼り付け、「確認する」で内容を見てから登録します。
- プロジェクト未設定があれば、Chatwork文をコピーして本人に送ります。
- 本人は自分用URLから修正します。
